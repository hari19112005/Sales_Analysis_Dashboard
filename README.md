# Sales Analysis using Excel

## Project Overview
An Excel-based Sales Analysis project developed to analyze sales performance, revenue, profit, and business trends using interactive dashboards.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning

## Key Analysis
- Total Sales and Revenue
- Profit Analysis
- Product Performance
- Regional Sales Performance
- Sales Trends
- Top-Performing Products

## Dashboard
Interactive Excel dashboard with KPIs, charts, Pivot Tables, and slicers.

## Files
- `Sales_Analysis_Dashboard.xlsx` – Excel dashboard and analysis

## Key Insights
The dashboard helps identify sales trends, profitable products, and areas of strong or weak business performance.
